# 🎉 Treasures of Innocence - New Website

## What I'm Building For You

A complete, modern NGO website from scratch with:

### ✅ Pages:
1. HOME - Hero, projects, impact stats, stories
2. OUR STORY - About the NGO
3. STEM Program - Full STEM content
4. Scholarship - All scholarship programs
5. Catch Them Young - Program details
6. Proyash - Youth empowerment
7. Contact - Contact form
8. Support Us - Donation page

### ✅ Features:
- Fully responsive (mobile, tablet, desktop)
- Fast loading
- SEO optimized
- Smooth animations
- Contact forms
- Modern design with your brand colors (Blue & Orange)

### ✅ Tech Stack:
- **Next.js 14** - React framework
- **Tailwind CSS** - Styling
- **Framer Motion** - Animations

---

## 🚀 How to Run It

### Step 1: Install Dependencies
```bash
npm install
```

### Step 2: Run Development Server
```bash
npm run dev
```

Open http://localhost:3000 in your browser

### Step 3: Build for Production
```bash
npm run build
npm start
```

## 🌐 Deployment (FREE on Vercel)

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin YOUR_GITHUB_REPO
git push -u origin main
```

### Step 2: Deploy on Vercel
1. Go to vercel.com
2. Sign up with GitHub
3. Import your repository
4. Click Deploy
5. Done! Your site is live
