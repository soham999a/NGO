## 💡 Quick Tips

### Adding an Element in Wix:
1. Click **+** button (left sidebar)
2. Choose element type (Button, Text, Box, etc.)
3. Drag it to your page
4. Click element → **Settings** (gear icon) → Set **ID**

### Element IDs Must Match Exactly:
- Code says: `#heroTitle`
- Wix ID should be: `heroTitle` (no # symbol)
- Case sensitive! `heroTitle` ≠ `HeroTitle`

### Colors to Use:
- Orange buttons: `#FF8C00`
- Blue buttons: `#2874A6`
- White text on dark backgrounds
- Dark text on light backgrounds
