# 🎯 WIX EDITOR QUICK GUIDE

## How to Add Elements in Wix

### Adding a Button
1. Click the **+** (Add) button on the left sidebar
2. Click **Button**
3. Drag it to your page
4. Double-click to change text
5. To set ID: Click button → Click **Settings** (gear icon) → Scroll to **ID** field → Enter the ID (like `donateBtn`)

### Adding Text
1. Click **+** → **Text**
2. Choose a text style (Heading, Paragraph, etc.)
3. Drag to page
4. Double-click to edit text
5. Set ID: Click text → **Settings** → **ID** field

### Adding a Strip/Section
1. Click **+** → **Strip**
2. Choose a layout
3. Drag to page
4. Add background image: Click strip → **Change Strip Background** → Upload image
5. Set ID in Settings

### Adding a Box/Card
1. Click **+** → **Box**
2. Drag to page
3. Add content inside (text, images, buttons)
4. Set ID in Settings

### Adding a Gallery
1. Click **+** → **Gallery**
2. Choose gallery type (Grid, Masonry, Slideshow)
3. Click **Manage Media** to upload photos
4. Set ID in Settings

### Adding an Image
1. Click **+** → **Image**
2. Click **Upload Media** → Choose your image
3. Drag to position
4. Set ID in Settings

---

## How to Change Element ID

1. Click the element
2. Click the **Settings** icon (gear) at the top
3. Scroll down to find **ID** field
4. Type your ID (no spaces, no special characters)
5. Click outside to save

**Example IDs:**
- `heroTitle`
- `donateBtn`
- `impactSection`
- `catchThemYoungCard`

## How to Style Elements

### Change Button Color
1. Click button
2. Click **Design** tab at top
3. Click **Customize Design**
4. Change **Fill Color** to your brand color
   - Orange: #FF8C00
   - Blue: #2874A6

### Change Text Color/Size
1. Click text
2. Use toolbar at top to change:
   - Font size
   - Color
   - Bold/Italic
   - Alignment

### Add Background Image to Strip
1. Click the strip
2. Click **Change Strip Background**
3. Click **Image** → **Upload Media**
4. Choose your image
5. Adjust **Image Settings** (fit, position, overlay)

## Layout Tips

### Make Elements Align Nicely
1. Select multiple elements (hold Shift + click)
2. Right-click → **Align** → Choose alignment
3. Or use **Distribute** to space evenly

### Add Padding/Spacing
1. Click strip/section
2. Drag the edges to make it taller/shorter
3. Or click **Settings** → Adjust **Height**

## Testing Your Page

1. Click **Preview** (eye icon) at top right
2. Or click **Test Site** to see it live
3. Check if animations work
4. Test buttons and links
5. View on mobile (click phone icon)

---

## Common Issues

**"I can't find the ID field"**
- Make sure you clicked the element first
- Click the Settings (gear) icon
- Scroll down - ID is usually near the bottom

**"My button doesn't work"**
- Check if the ID matches exactly (case-sensitive!)
- Make sure you saved the page
- Refresh the preview

**"Animation not showing"**
- Elements might be set to "Hidden" initially
- Click element → **Settings** → Make sure **Hidden on load** is checked for animated elements
