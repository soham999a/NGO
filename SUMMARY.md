## 🆘 Common Issues & Solutions

**"Animation not working"**
→ Check element ID matches code exactly

**"Button doesn't navigate"**
→ Verify target page exists and URL is correct

**"Counter doesn't count"**
→ Make sure initial text is "0"

**"Gallery not clickable"**
→ Check gallery ID and ensure images are added

**"Form doesn't submit"**
→ Verify all form field IDs match code
